## 卡在哪、怎么解决

| 卡点 | 原因 | 解决 |
|---|---|---|
| 小狐狸里找不到「显示测试网络」开关 | 新版手机 App 已删除该开关；且「账户」页那个下拉是多链地址视图，不是网络切换 | 放弃 UI 切换网络，改用 `cast send`，网络由 `--rpc-url` 决定 |
| `vm.envUint: failed parsing $PRIVATE_KEY ... missing hex prefix` | 小狐狸导出的私钥不带 `0x` | `.env` 里补 `0x` 前缀 |
| 部署脚本里 `cast: command not found` | 非交互 shell 不读 `~/.zshrc` | 脚本内兜底把 `~/.foundry/bin` 加进 PATH |
| 轮询回调时 `count: unbound variable` | `$count（` 中 Bash 把全角括号字节吞进变量名 | 改用 `${count}` 加大括号 |
